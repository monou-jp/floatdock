Add CTA UI to any site
with one script tag.

floatdock は、既存サイトに <script> 1行で フローティング / 下部固定 / 展開メニュー（FAB） の導線UIを追加する軽量ウィジェットです。 PCとスマホで表示方式を切り替え、スクロール時に隠す挙動も設定できます。

Features

Single script

既存サイトに <script src=".../floatdock.js"> 1行で導入できます。

Device modes

PC/スマホで表示方式を切替（スマホは 3モード）。

Hide on scroll

スクロール中は隠して、必要時だけ表示（設定で調整）。

Vanilla JS

依存ライブラリ無し。WordPress等でも扱いやすい構成です。

Customizable

文言、位置、サイズ、色、リンク先を設定可能。

Accessible (basic)

基本的な aria-label を付与（必要に応じて拡張）。

Modes

Desktop
• floating（右下/右上/左下/左上）
• サイズ・文言・サブラベルを設定
Mobile
• bottom-bar：下部固定2ボタン
• floating：丸/角丸ボタン
• expand-fab：タップで縦展開メニュー
スマホ判定は window.innerWidth < breakpoint（User-Agentは使用しません）。

Quick start

<!-- 1) floatdock.js を配置（GitHub Pages / 自社ドメインなど） -->

<!-- 2) 既存サイトの <head> に1行追加 -->
<script src="https://your-domain/floatdock.js" defer></script>

<!-- 任意：ページ側から設定を差し込む（デモ・検証向け） -->
<script>
window.FLOATDOCK_CONFIG = {
  lineUrl: "https://lin.ee/xxxxxx",
  contactUrl: "tel:0120-000-000",
  display: { desktop: "floating", mobile: "bottom-bar" },
  hideOnScroll: { enabled: true }
};
</script>
<script src="https://your-domain/floatdock.js" defer></script>
Recommended operational style

本番運用は「設定も floatdock.js 内に内蔵」し、設置は <script> 1行だけにするのが最も安全・簡単です。 ページ側上書き（window.FLOATDOCK_CONFIG）はデモや検証用途に向きます。

Config (minimal)

window.FLOATDOCK_CONFIG = {
  breakpoint: 768,
  lineUrl: "https://lin.ee/xxxxxx",
  contactUrl: "/contact",
  display: {
    desktop: "floating",
    mobile: "bottom-bar" // "bottom-bar" | "floating" | "expand-fab"
  },
  hideOnScroll: {
    enabled: true,
    hideDirection: "down",
    hideAfter: 120,
    minDelta: 10
  }
};
さらに細かい設定（色、位置、FAB items、アイコン等）は floatdock.js のデフォルト値を参照してください。

Common config tips

lineUrl contactUrl breakpoint display.mobile hideOnScroll
  • 電話導線は tel: を使えます（例: tel:0120-000-000）。
  • 外部URLは原則新規タブ、同一オリジンは同一タブに遷移する挙動（実装側で変更可）。
  • スマホ回転・ウィンドウサイズ変更に追従して自動でモードを切り替えます。

Constraints / Why it may not work

1) CSP (Content Security Policy)
サイト側で CSP が厳しい場合、以下がブロックされることがあります。
  • 外部ドメインの <script> 読み込み
  • <style> の動的挿入（表示は出てもCSSが当たらない）
How to check

DevTools → Network → 対象HTML → Response headers に Content-Security-Policy または Content-Security-Policy-Report-Only があるか確認してください。

Typical blocking example

Content-Security-Policy: script-src 'self';

Workarounds

最も確実：floatdock.js を同一ドメインに設置。
CSPを変更できる場合：script-src に配布先ドメインを許可し、必要なら style-src 側も調整してください（管理者・制作会社への依頼が必要です）。

2) Tag Manager / 3rd-party injection
GTM等のタグマネージャ経由で設置する場合、環境によっては position: fixed や z-index の挙動が想定と異なることがあります。
  • 推奨：<head> に直接 <script> を追加
  • 代替：同一ドメイン配信 + CSP調整
3) SPA / Client-side routing
React/Vueなどでページ遷移時にDOMが再生成される場合、ウィジェットが消えることがあります。
その場合はルーティング後に LineWidget.update() を呼び出してください。 
// Example (after route change)
if (window.LineWidget && typeof window.LineWidget.update === "function") {
  window.LineWidget.update();
}
Terminology note

ここで言う「CSP」はセキュリティヘッダの Content Security Policy を指します （CPA=広告指標とは別です）。CSPが有効だと、外部JSの読み込みや動的CSS注入が制限される場合があります。

Useful notes

Click tracking (GA4 / Ads)
floatdock は計測SDKに依存しません。必要ならクリックイベントで gtag / dataLayer などを呼び出してください。 
// Example: GA4 event
a.addEventListener("click", function () {
  if (window.gtag) {
    gtag("event", "click", {
      event_category: "floatdock",
      event_label: "line"
    });
  }
});
Accessibility (basic)
ボタンには aria-label を付与し、基本的な操作性を確保します。
WCAG等の厳密準拠が必要な場合は、フォーカス制御やキーボード操作の拡張を推奨します。
Trademark / icons
floatdock は商標ロゴ画像に依存しません（汎用SVGを使用）。
公式ロゴを使う場合は各サービスのガイドラインに従ってください。

Troubleshooting

Not showing
  • CSPで script-src が制限されていないか（#Constraints参照）
  • floatdock.js が 404 になっていないか（Networkで確認）
  • 他要素の z-index が極端に高くないか
  • 画面幅が breakpoint を跨いでモードが変わっていないか
Cannot click
  • 上に透明な要素が被っていないか（DevToolsで要素確認）
  • 親要素に pointer-events: none が掛かっていないか
  • iframe内で動かしている場合は、親側の制限により挙動が変わることがあります
SPA pages (disappear after navigation)
ルーティング後に再生成してください。
window.LineWidget?.update?.();
Support tip

問題が出る場合、まず「対象ページのレスポンスヘッダ（CSPの有無）」と「Consoleのエラー」を確認すると原因切り分けが速くなります。
